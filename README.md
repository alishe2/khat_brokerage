# KhatBrokerage

KhatBrokerage is a Flutter mobile application designed to support khat brokerage business operations.

### Technologies
- Flutter and Dart
- Supabase

### Main Features
- User authentication
- Admin and accountant dashboards
- Transaction and expense management
- Reports and profile management

### Project Structure
- `lib/` — Contains the application's source code.
- `video/` — Contains the project demonstration video.
- `pubspec.yaml` — Contains project dependencies and configuration.

### Demo Video
The project demonstration video is available in the [`video/`](./video/) folder.

**Video:** `video/KhatBrokerage_Demo.mp4`
